# GiftDrop

A polished, responsive digital-gifting website prototype.

## Run
No installation is required.

1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Click **Explore Gifts**.
4. Select a template.
5. Customize the recipient, title and message.
6. Save the gift and open the generated gift page.

## Included
- Responsive landing page
- Gift template library
- Live customization preview
- LocalStorage-based demo gift persistence
- Share button / copy-link fallback
- Login demo
- Dashboard demo

## Production upgrades
For a real SaaS product, connect:
- Authentication: Firebase/Auth0/Supabase
- Database: MongoDB/PostgreSQL/Supabase
- Image storage: Cloudinary/S3/Supabase Storage
- Payments: Razorpay/Stripe
- QR: a QR-code library
- Email/WhatsApp delivery APIs
- Real private gift URLs and access controls
